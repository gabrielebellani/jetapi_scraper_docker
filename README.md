# jetapi

An API-only service that gathers information from JetPhotos and FlightRadar24.

This repository provides a small HTTP service that exposes a single API endpoint to query aircraft information and images by registration.

Files of interest:
- [Dockerfile](Dockerfile)
- [docker-compose.yml](docker-compose.yml)
- [cmd/jetapi/main.go](cmd/jetapi/main.go)

## Build & Run (recommended)
The project is containerized. From the repository root build and start the service with Docker Compose:

```bash
docker compose up --build -d
```

The service listens on port `8922` by default. To stop:

```bash
docker compose down
```

## Environment
- `PORT` (default `8922`) — port the service binds to inside the container
- `HOST` (default `0.0.0.0`) — host the service binds to

These are already set in the provided [Dockerfile](Dockerfile) and [docker-compose.yml](docker-compose.yml).

## API Usage
Endpoint: `GET /api`

Required query parameter:
- `reg` — aircraft registration (alphanumeric, may include `-`)

Optional query parameters:
- `only_jp=true` — return only JetPhotos results (images)
- `only_fr=true` — return only FlightRadar results
- `photos=<n>` — number of JetPhotos images to fetch (default: 3)
- `flights=<n>` — number of FlightRadar flights to fetch (default: 20)

Examples:

Fetch 3 JetPhotos images for registration `EI-DCL`:

```bash
curl "http://localhost:8922/api?reg=EI-DCL&only_jp=true&photos=3"
```

Fetch both JetPhotos and FlightRadar data (default counts):

```bash
curl "http://localhost:8922/api?reg=EI-DCL"
```

Extract only image URLs (requires `jq`):

```bash
curl -s "http://localhost:8922/api?reg=EI-DCL&only_jp=true&photos=5" | jq -r '.Images[].Image'
```

Notes on responses:
- When `only_jp=true` the endpoint returns a `JetPhotos` result with `Reg` and `Images` (each image contains `Image`, `Link`, `Thumbnail`, `DateTaken`, `Location`, etc.).
- When neither `only_jp` nor `only_fr` is specified the response includes both `JetPhotos` and `FlightRadar` results in a combined JSON structure.

## Run locally (without Docker)
If you have Go installed you can run directly:

```bash
go run ./cmd/jetapi
```

Set `HOST` and `PORT` as needed in the environment before running.

## Troubleshooting
- View container logs:

```bash
docker compose logs -f jetapi
```

- If build fails inside Docker, try building locally to get faster diagnostics:

```bash
go build -o ./bin/jetapi ./cmd/jetapi
./bin/jetapi
```

## Limitations
- The scraper works best for commercial airliners; some GA aircraft or registrations not present on the upstream sites can cause partial or empty results.
